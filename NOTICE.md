## 1. Algorithmic attribution

The numerical methods implemented in this library are derived from the following
sources. If you use this library in academic work, please cite them; see
`CITATION.cff` for machine-readable records.

- **Eigenvalues.** Closed-form evaluation of the eigenvalues of 3×3 matrices via
  the trace and deviatoric invariants with a stabilized discriminant, after:
  Michal Habera and Andreas Zilian, "Numerically stable evaluation of closed-form
  expressions for eigenvalues of 3×3 matrices," arXiv:2511.00292 [math.NA], 2025.
  <https://doi.org/10.48550/arXiv.2511.00292>

- **Eigenvectors.** Null-space construction of eigenvectors from known
  eigenvalues, after: David H. Eberly, "A Robust Eigensolver for 3x3 Symmetric
  Matrices," Geometric Tools, LLC.
  <https://www.geometrictools.com/Documentation/RobustEigenSymmetric3x3.pdf>

Mathematical methods as such are not subject to copyright; this attribution is
maintained as scholarly courtesy regardless of whether any source code was reused.
